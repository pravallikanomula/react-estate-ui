# 🏠 Full Stack Real Estate App

A full-stack **React & Node.js** real estate application with **MongoDB** for database management and **Socket.io** for real-time chat. This app allows users to **buy, sell, and rent houses, condos, and apartments** with role-based access for buyers, sellers, and admins.  

---

## 🧠 Features

- Browse and filter listings by **price, type, and location**  
- **Buy, sell, or rent** properties  
- **Real-time chat** between buyers and sellers using Socket.io  
- **User authentication & role-based access** (Buyer, Seller, Admin)  
- Interactive **React Map** integration to visualize property locations  
- Responsive UI for desktops and mobile devices  

---

## 🧰 Tech Stack

- **Frontend:** React.js, Context API, React Router Dom, HTML, CSS  
- **Backend:** Node.js, Express.js, Prisma  
- **Database:** MongoDB  
- **Authentication & Security:** JWT, Cookies  
- **Real-time Communication:** Socket.io
